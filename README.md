# Space-Exam 🚀

An advanced examination system designed for space-related studies and assessments.

## 📋 Description

Space-Exam is a comprehensive examination platform built to manage and conduct space-related examinations. This system provides an intuitive interface for creating, administering, and grading space science exams with various question types and assessment capabilities.

## ✨ Features

- **Exam Management** - Create, edit, and manage multiple exams
- **Question Bank** - Organize questions by category and difficulty level
- **Multiple Question Types** - Support for multiple choice, true/false, short answer, and essay questions
- **Automated Grading** - Automatic scoring for objective questions
- **User Management** - Student and instructor account management
- **Results & Analytics** - Detailed performance analytics and reporting
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Security** - Secure exam sessions with authentication

## 🛠️ Technology Stack

- **Frontend** - HTML, CSS, JavaScript
- **Backend** - Node.js / Express (if applicable)
- **Database** - MongoDB / SQL (if applicable)
- **Version Control** - Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Git installed on your system
- Node.js (v14 or higher) - if backend is included

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/Reem-Yousef/Space-Exam.git
cd Space-Exam
```

2. **Navigate to the project directory:**
```bash
cd Space-Exam
```

3. **Open in browser:**
   - Simply open `index.html` in your web browser, or
   - Use a local development server

**Using Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Using Node.js (if applicable):**
```bash
npm install
npm start
```

4. **Access the application:**
   - Open your browser and navigate to `http://localhost:8000`

## 📖 Usage

### For Students
1. Log in with your student credentials
2. View available exams
3. Start an exam from the exam list
4. Answer questions carefully
5. Submit your responses
6. View your results and feedback

### For Instructors
1. Log in with instructor credentials
2. Create new exams and questions
3. Set exam parameters (duration, passing score, etc.)
4. Monitor student progress
5. View and analyze exam results
6. Generate performance reports

## 🎓 Exam Types Supported

- **Multiple Choice** - Select one correct answer from options
- **True/False** - Boolean questions for quick assessment
- **Short Answer** - Brief text responses
- **Essay** - Longer form answers for detailed assessment
- **Matching** - Match items from two lists

## 📊 Features in Detail

### Question Management
- Create questions with multiple formats
- Add multimedia (images, videos)
- Set difficulty levels and learning objectives
- Organize in categories

### Exam Settings
- Configure duration and time limits
